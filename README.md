# MatHEr1al
A converter for Hedgehog Engine 1 (and 2) .material files

To use MatHEr1al, type in your console:
```python [path to MatHEr1al.py] [path to .xml or .material]```

If ``python`` doesn't work, use ``python3``;
output will be in the same directory as input; 
.texset and .texture are found using data in .material
